MR, KHORASANI Web PWA 2.7.1

این بسته شامل رابط کامل حسابداری نسخه وب با محیط مهمان مستقل، ذخیره نشست‌محور در مرورگر، گزارش رویدادهای مهمان، نصب PWA و فایل‌های لازم برای GitHub Pages است.

برای انتشار در ریشه GitHub Pages، محتویات همین پوشه را در ریشه شاخه main قرار دهید. نشانی API مهمان از طریق supabase-config.js و URL ثابت در index.html تنظیم شده است.
