MR, KHORASANI Web PWA 2.7.2

این بسته شامل رابط کامل حسابداری نسخه وب با محیط مهمان مستقل، ثبت آزمایشی عملیات، گزارش فعالیت نشست، نصب PWA و فایل‌های لازم برای GitHub Pages است.

حریم داده مهمان:
- تمام اسناد و وضعیت کاری مهمان فقط در sessionStorage همان تب مرورگر ذخیره می‌شود؛ از localStorage، IndexedDB و جداول مالی شرکت استفاده نمی‌شود.
- داده‌های همان نشست پس از refresh قابل بازیابی است؛ با خروج صریح، پایان اعتبار نشست یا بسته شدن تب پاک می‌شود.
- عملیات مهمان هرگز به دفاتر، موجودی، اسناد، حساب‌ها یا فایل نسخه اصلی و Android ارسال نمی‌شود.
- گزارش مدیریتی جداگانه، بازدید صفحه، کلیک، تغییر فیلد، ارسال فرم و ثبت/ویرایش/حذف عملیات را نگه می‌دارد؛ جزئیات صرفاً پاک‌سازی‌شده مالی است.
- مقدار خام فیلدهای هویتی، تماس، آدرس، حساب/کارت، رمز و متن آزاد فرم‌ها وارد گزارش نمی‌شود.
- خروجی‌هایی که کاربر خودش دانلود، چاپ یا خارج از مرورگر ذخیره کند، توسط پاک‌سازی نشست حذف نمی‌شوند.

نصب روی دستگاه:
- Android و دسکتاپ: از منوی مرورگر Install app / نصب برنامه را انتخاب کنید.
- iPhone و iPad: در Safari گزینه Share و سپس Add to Home Screen را بزنید.
- این بسته PWA است و روی Android، iOS و دسکتاپ قابل نصب است؛ APK فقط برای Android قابل استفاده است.

برای انتشار روی GitHub Pages، محتویات ریشه همین بسته در ریشه شاخه main قرار می‌گیرد. آدرس API مهمان در supabase-config.js و index.html تنظیم شده است.
