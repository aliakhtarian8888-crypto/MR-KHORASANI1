# MR, KHORASANI — شاخه poshtiban-Q-baha

این شاخه برای ارتقای نسخه 2.10.0 به 2.11.0-poshtiban-Q-baha در نظر گرفته شده است.

## وضعیت انتقال سورس
شاخه فعلی از commit نسخه 2.10.0 ساخته شده است و هنوز سورس کامل 2.11.0 روی آن جایگزین نشده است. تا وقتی محتوای ZIP سخت‌سازی‌شده/نسخه 2.11.0 در ریشه شاخه بارگذاری و Commit نشده، این URL را برای کاربران نهایی منتشر نکنید.

## بسته‌های آماده انتقال
از فایل‌های ZIP تحویلی در گفت‌وگوی MR,KHORASANI استفاده کنید:
- WEB/PWA: فایل مستقل وب/PWA
- Android SOURCE: پروژه کامل سورس و Gradle
- iOS PWA: بسته نصب‌پذیر Safari/PWA (نه IPA)

برای انتقال کامل، محتوای ZIP وب/PWA را در ریشه Pages و محتوای ZIP Android SOURCE را به عنوان سورس کامل در شاخه جایگزین کنید. پس از Commit، تست‌های Node و Workflow ساخت Android را اجرا کنید. QRهای داخل بسته به نشانی GitHub Pages همین مخزن اشاره می‌کنند؛ تا زمان انتشار Pages از نسخه 2.11.0، QRها را به مشتری ندهید.

## نکات انتشار
- Android ZIP تحویلی در این مرحله شامل سورس است؛ APK باینری ساخته‌شده نیست.
- iOS ZIP تحویلی PWA است؛ ساخت IPA به macOS/Xcode و گواهی Apple Developer نیاز دارد.
- هیچ داده واقعی شرکت را برای تست مهمان یا مهاجرت با داده نمونه جایگزین نکنید.
- پیش از استقرار عملیاتی، بکاپ/بازیابی روی محیط آزمایشی و تراز/کاردکس را کنترل کنید.
