MR, KHORASANI — بسته نصب اندروید سازمانی نسخه ۲.۹.۴

این بسته فقط برای کاربران سازمانی دارای حساب مجاز است. فایل داخل آن APK واقعیِ ساخته‌شده با پروژه Android است، نه صفحه HTML یا PWA.

ورود:
- کاربر با ایمیل و رمز حساب سازمانی خود وارد می‌شود.
- مدیر سیستم کاربران جدید را از داخل برنامه ایجاد می‌کند و نقش و مجوز هر بخش را تعیین می‌کند.
- کاربر مهمان در APK وارد نمی‌شود؛ ورود مهمان فقط با QR مرورگری جداگانه انجام می‌شود.

ماندگاری اطلاعات:
- عملیات کاربران سازمانی پس از احراز هویت به شرکت فعال و پایگاه داده مرکزی همگام می‌شود.
- سوابق با سطح دسترسی و مسیر حسابرسی نگهداری می‌شوند و مدیر مجاز می‌تواند مطابق مجوزها آن‌ها را بررسی یا اصلاح کند.
- این خروجی Debug است. برای انتشار تجاری و به‌روزرسانی بدون حذف نصب قبلی، APKهای Release باید با کلید امضای پایدار مالک سامانه ساخته شوند.

QR داخل این بسته فقط صفحه دریافت همین APK را باز می‌کند.
